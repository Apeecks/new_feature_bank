# Проект банковских операций

Проект содержит функции для обработки данных банковских карт, счетов и операций.

## Установка

Клонируйте проект и установите зависимости через Poetry:

```bash
poetry install
```

### Фильтрация операций по статусу

```python
filter_by_state(operations)
```

По умолчанию возвращаются операции со статусом:

```text
EXECUTED
```

Можно передать другой статус:

```python
filter_by_state(operations, "CANCELED")
```

### Сортировка операций по дате

```python
sort_by_date(operations)
```

По умолчанию операции сортируются по дате по убыванию.

Для сортировки по возрастанию:

```python
sort_by_date(operations, False)
```


## Модуль generators

Модуль `generators` содержит функции-генераторы для работы с данными банковских транзакций.

### `filter_by_currency`

Функция принимает список транзакций и код валюты и возвращает итератор с транзакциями, выполненными в указанной валюте.

Пример использования:

```python
from src.generators import filter_by_currency

usd_transactions = filter_by_currency(transactions, "USD")

for transaction in usd_transactions:
    print(transaction)
```

### `transaction_descriptions`

Функция-генератор принимает список транзакций и поочередно возвращает описание каждой операции.

Пример использования:

```python
from src.generators import transaction_descriptions

descriptions = transaction_descriptions(transactions)

for description in descriptions:
    print(description)
```

Пример результата:

```text
Перевод организации
Перевод со счета на счет
Перевод с карты на карту
```

### `card_number_generator`

Генератор принимает начальное и конечное значения диапазона и поочередно генерирует номера банковских карт в формате `XXXX XXXX XXXX XXXX`.

Пример использования:

```python
from src.generators import card_number_generator

for card_number in card_number_generator(1, 4):
    print(card_number)
```

Результат:

```text
0000 0000 0000 0001
0000 0000 0000 0002
0000 0000 0000 0003
```


## Модуль decorators

Модуль `decorators` содержит декораторы для дополнительной обработки функций.

### Декоратор `log`

Декоратор `log` используется для логирования выполнения функций.

Он позволяет:

* логировать начало и завершение выполнения функции;
* сохранять результат выполнения функции;
* логировать информацию об ошибках;
* выводить логи в консоль;
* записывать логи в файл при указании параметра `filename`.

### Логирование в консоль

Если параметр `filename` не указан, информация о выполнении функции выводится в консоль.

Пример:

```python
from src.decorators import log


@log()
def division(a: int, b: int) -> float:
    return a / b


division(4, 2)
```

### Логирование в файл

Если передать параметр `filename`, логи будут записываться в указанный файл.

Пример:

```python
from src.decorators import log


@log(filename="log.txt")
def add(a: int, b: int) -> int:
    return a + b


add(2, 3)
```

В результате информация о выполнении функции будет записана в файл `log.txt`.

### Логирование ошибок

Если во время выполнения функции возникает ошибка, декоратор записывает информацию об ошибке и переданных аргументах.

Пример:

```python
from src.decorators import log


@log()
def division(a: int, b: int) -> float:
    return a / b


division(4, 0)
```

В лог будет записана информация о возникшей ошибке и входных параметрах функции.



## Работа с JSON и конвертация валют

В проект добавлен функционал для чтения данных о банковских транзакциях из JSON-файла и конвертации суммы операции в рубли.

### Модуль `utils`

В модуле `src/utils.py` реализована функция `path_to_file_json`, которая принимает путь к JSON-файлу и возвращает список транзакций.

Если файл:

* не найден;
* пустой;
* содержит некорректный JSON;
* содержит данные, которые не являются списком,

функция возвращает пустой список.

Пример использования:

```python
from src.utils import path_to_file_json

transactions = path_to_file_json("data/operations.json")

print(transactions)
```

### Модуль `external_api`

В модуле `src/external_api.py` реализована функция `exchange`, которая принимает словарь с данными о транзакции и возвращает сумму операции в рублях в формате `float`.

Если операция выполнена в рублях, сумма возвращается без обращения к внешнему API.

Для операций в иностранной валюте выполняется запрос к Exchange Rates Data API для получения результата конвертации в рубли.

Пример использования:

```python
from src.external_api import exchange

transaction = {
    "operationAmount": {
        "amount": "8000",
        "currency": {
            "name": "USD",
            "code": "USD",
        },
    }
}

result = exchange(transaction)

print(result)
```

## Работа с CSV и XLSX

В проект добавлена поддержка чтения финансовых операций из файлов форматов CSV и XLSX.

Для работы с XLSX используется библиотека pandas.

### Модуль read_transactions.py

#### Реализованы функции:

- read_transactions_csv — считывает финансовые операции из CSV-файла и возвращает список словарей.
- read_transactions_xlsx — считывает финансовые операции из XLSX-файла и возвращает список словарей.
- Если файл не найден, функции возвращают пустой список.

### Переменные окружения

API-ключ хранится в файле `.env`.

Пример:

```text
APILayer_KEY=your_api_key
```

В репозитории находится файл `.env.example` с шаблоном необходимых переменных окружения.

Файл `.env` не должен добавляться в Git.



## Тестирование

В проекте используется библиотека `pytest`.

Для запуска тестов выполните:

```bash
pytest
```

Для проверки покрытия функционального кода тестами:

```bash
pytest --cov=src
```

Для создания отчета покрытия тестами в формате HTML:

```bash
pytest --cov=src --cov-report=html
```

В проекте используются фикстуры для создания необходимых входных данных для тестов и параметризация для тестирования функциональности с различными входными данными.

Функциональный код покрыт тестами на 100%.
