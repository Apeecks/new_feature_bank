# Проект банковских операций

Проект содержит функции для обработки данных банковских карт, счетов и операций.

## Установка

Клонируйте проект и установите зависимости через Poetry:

```bash
poetry install
```

## Функции

### Маскировка номера карты

```python
get_mask_card_number("7000792289606361")
```

Результат:

```text
7000 79** **** 6361
```

### Маскировка номера счета

```python
get_mask_account("73654108430135874305")
```

Результат:

```text
**4305
```

### Маскировка карты или счета

```python
mask_account_card("Visa Platinum 7000792289606361")
```

Результат:

```text
Visa Platinum 7000 79** **** 6361
```

```python
mask_account_card("Счет 73654108430135874305")
```

Результат:

```text
Счет **4305
```

### Форматирование даты

```python
get_date("2024-03-11T02:26:18.671407")
```

Результат:

```text
11.03.2024
```

### Фильтрация операций по статусу

```python
filter_by_state(operations)
```

По умолчанию возвращаются операции со статусом:

```text
EXECUTED
```

Можно передать другой статус:

```python
filter_by_state(operations, "CANCELED")
```

### Сортировка операций по дате

```python
sort_by_date(operations)
```

По умолчанию операции сортируются по дате по убыванию.

Для сортировки по возрастанию:

```python
sort_by_date(operations, False)
```
